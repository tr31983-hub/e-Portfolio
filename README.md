
# 🌐 My E-Portfolio Website

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) ที่จัดทำขึ้นเพื่อรวบรวมข้อมูลส่วนตัว ประวัติการศึกษา ความสามารถ กิจกรรม และผลงานต่าง ๆ ไว้ในเว็บไซต์เดียว

## 📌 เกี่ยวกับโปรเจกต์

My E-Portfolio เป็นเว็บไซต์ที่พัฒนาด้วย HTML, CSS และ JavaScript โดยมีจุดประสงค์เพื่อใช้เป็นพื้นที่นำเสนอข้อมูลและผลงานของตนเองในรูปแบบออนไลน์ ช่วยให้ผู้เข้าชมสามารถทำความรู้จักและดูผลงานได้อย่างสะดวกและเป็นระเบียบ

เว็บไซต์ได้รับการออกแบบให้มีความทันสมัย เรียบง่าย และใช้งานง่าย รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## ✨ คุณสมบัติของเว็บไซต์

- 🏠 **Home:** หน้าแรกแนะนำตัวและแสดงรูปโปรไฟล์
- 👤 **About Me:** แสดงประวัติส่วนตัวและข้อมูลเบื้องต้น
- 📚 **Education:** แสดงประวัติการศึกษา
- 🏆 **Activities & Achievements:** รวบรวมกิจกรรมและผลงานที่ผ่านมา
- 📞 **Contact:** แสดงช่องทางการติดต่อ
- 📱 **Responsive Design:** รองรับการแสดงผลบนอุปกรณ์หลายขนาด
- 🎨 **Modern UI:** ออกแบบด้วยโทนสีฟ้าและขาว ดูสะอาดตา

## 🛠️ เครื่องมือและเทคโนโลยีที่ใช้

| เทคโนโลยี | การใช้งาน |
|---|---|
| HTML5 | สร้างโครงสร้างเว็บไซต์ |
| CSS3 | ตกแต่งและออกแบบเว็บไซต์ |
| JavaScript | รองรับการพัฒนาฟังก์ชันเพิ่มเติม |
| Google Fonts | ใช้แบบอักษร Prompt |

## 📂 โครงสร้างโปรเจกต์

```text
My-E-Portfolio/
│
├── index.html
└── README.md
```

## 🚀 วิธีติดตั้งและใช้งาน

1. ดาวน์โหลดหรือ Clone โปรเจกต์จาก GitHub
2. เปิดโฟลเดอร์โปรเจกต์
3. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์
4. แก้ไขข้อมูลส่วนตัว รูปภาพ และผลงานให้เป็นของตนเอง

สามารถใช้งานได้โดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

## 🎯 วัตถุประสงค์ของการพัฒนา

1. เพื่อฝึกทักษะการพัฒนาเว็บไซต์ด้วย HTML และ CSS
2. เพื่อเรียนรู้การออกแบบหน้าเว็บไซต์ให้สวยงามและใช้งานง่าย
3. เพื่อรวบรวมประวัติส่วนตัวและผลงานในรูปแบบดิจิทัล
4. เพื่อพัฒนาทักษะด้านเทคโนโลยีสารสนเทศ
5. เพื่อสร้างผลงานสำหรับนำเสนอประวัติและความสามารถของตนเอง

## 📖 สิ่งที่ได้รับจากการทำโปรเจกต์

จากการพัฒนาเว็บไซต์ E-Portfolio ทำให้ได้เรียนรู้เกี่ยวกับการเขียน HTML เพื่อสร้างโครงสร้างเว็บไซต์ การใช้ CSS ในการตกแต่งและจัดวางองค์ประกอบ รวมถึงการออกแบบเว็บไซต์ให้รองรับหน้าจอหลายขนาด

นอกจากนี้ยังได้ฝึกทักษะการคิดสร้างสรรค์ การแก้ไขปัญหา และการจัดระเบียบข้อมูลให้อยู่ในรูปแบบที่เข้าใจง่ายและน่าสนใจ

- เพิ่มระบบเปลี่ยนธีมเว็บไซต์
- เพิ่มแอนิเมชันและลูกเล่นต่าง ๆ
- เพิ่มระบบจัดการข้อมูลผลงาน
